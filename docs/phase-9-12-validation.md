## 浏览器实际操作

- 未登录提交 → 登录 → 自动生成 → 保存 → 作品详情；刷新详情后图片、短句和原文保留。
- 收藏后在我的收藏出现；公开后进入广场；点赞从 0 变为 1，可取消。
- 广场和公开详情不含原文、analysis 或 generationPrompt；作者访问公开详情也不显示原文折叠区。
- 下载得到本地 SVG；不支持 Web Share 时复制带 `?view=public` 的链接，并明确提示不能跨设备访问。
- 第二个标签页打开广场，作者取消公开后该标签页自动变为空状态。
- 退出后私密详情不显示原文，登录后可返回原作品。
- 删除弹窗初始焦点在取消；Escape 关闭并返回删除按钮；确认删除后我的作品、收藏和旧详情地址均无记录。
- 模拟存储空间不足：完成图片保留，恢复存储后「重试保存」成功，生成请求计数仍为 1，存储作品数量仍为 1。
- 三幅实际生成作品验证个人页统计：作品 3、收藏 1、公开 3。
- 375px 的广场、详情页均无横向溢出，桌面三列画廊及手机布局已截图。
- 最终复核手机导航、收藏切换和公开详情，正常流程无控制台错误。

## 边界

数据只保存在同一来源的当前浏览器内，不是云端广场。清除浏览器数据后不可恢复。共享浏览器的人可检查 LocalStorage，Mock 登录不提供真实账号隔离；Repository 的 UI 隐私规则需要未来服务端权限实现配合。
