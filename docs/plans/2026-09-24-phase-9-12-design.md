# Phase 9–12 实施范围

沿用既有 UI → Service → Provider / Repository 架构，以及米白、克制的艺术画廊视觉。首页和生成三阶段布局保持不变。

- 详情页 `/artwork/[id]` 以作品为主体，提供保存、收藏、下载、分享、公开和确认删除；仅本人可折叠查看原文。
- LocalStorage 使用单一带版本信封保存作品与用户交互。生成保存默认私密，按生成 ID 幂等写入。存储失败时保留当前结果供重试，不重新调用生成服务。
- 私密记录通过 owner API 读取；公共列表和详情通过明确投影读取。公开详情以 `?view=public` 区分本人私密视图。
- `/me`、`/me/artworks`、`/me/favorites` 使用登录保护，`/gallery` 可匿名浏览公开投影。收藏和点赞需登录。
- 删除使用原生 modal dialog，默认聚焦取消、支持 Escape 和关闭后焦点恢复；数据删除同时清理所有收藏与点赞引用。
- Web Share 优先，Clipboard 降级；分享说明当前为本浏览器原型。不会接真实身份认证、数据库或云存储。

验证以实际生成→持久化→收藏→公开→取消公开→刷新→删除的流程为主，辅以 Repository 多身份隔离、损坏/配额故障测试和桌面/手机截图。
