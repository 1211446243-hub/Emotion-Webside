# Phase 1–2 实施边界

依据用户提供的完整产品说明，本次只搭建基础工程及首页。

## 视觉方案

采用米白纸面、炭黑文字、宋体标题与清晰的无衬线正文。相比大幅封面图或深色沉浸首页，文字居中的编辑式布局更符合「先看到一个问题」的目标。主输入区限制在 760px，页面整体版心为 1200px。首页下方三幅 CSS 抽象构图仅作为视觉占位，不冒充生成作品。

## 结构

App Router 服务端 Layout 和首页负责静态内容，移动菜单与输入框为独立客户端组件。品牌名仅配置在 config/site.ts。Provider、Auth、Repository、types 和本地图片目录预留，具体接口及实现留待后续阶段。

## 输入行为

初始化后随机选一次原创提示，不轮播；输入区自动增高至上限后内部滚动。去掉首尾空白后至少两个字符才可提交，最多 1000 个 Unicode 码点。Enter 和 Shift+Enter 都换行。按钮点击只告知生成尚未开放，保留文字，不进入后续流程，不存储或发送输入。

## 验证

Phase 1 完成时构建，Phase 2 完成后运行 ESLint 与构建。启动页面，检查 375px、1440px 的布局、菜单键盘操作、空白及边界输入、换行与提示稳定性。阶段外的登录、生成、作品管理和广场不实现。
