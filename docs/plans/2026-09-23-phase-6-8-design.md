# Phase 6–8 实施范围

沿用原有目录和抽象，不改首页排版。首页提交进入 `/create`，未登录则先登录再自动返回该路由。

采用本地 SVG 艺术化占位图，符合初版没有实际图片时的占位方案。比远程图片更易离线复现，也不需要任何真实 API；不提前建立完整图库。

服务端 GenerationService 通过注入的 Provider 编排流程，本地 Route Handler 将阶段事件流式传给客户端 service facade。选择这一方案是为了保持供应商代码留在服务端，未来替换真实 Provider 不需移动 UI 中的分析逻辑。

三段 Mock 延迟集中配置。UI 呈现模糊画布、颜色与形状、最终清晰图片；完成前预加载资源，支持 reduced motion。离开页面、退出登录会取消；失败可以重试，并保留原始文字。

本阶段只创建 Artwork 对象并展示于生成页，不提前做 Phase 9 的作品操作与 Phase 10 的持久化。刷新后显示明确空状态。

验证包含服务编排、图片选择、隐私默认值、断流、错误、取消、真实浏览器三阶段、登录连续性、375/1440px、减少动画和构建。
